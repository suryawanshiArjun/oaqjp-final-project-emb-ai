# Final Project

## Emotion Detection Application

This Final Project demonstrates an emotion detection application that analyzes text and identifies five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

The application uses the Watson NLP Emotion Prediction service to identify the dominant emotion in the input text.

### Technologies Used

- Python
- Flask
- Requests
- Watson NLP Emotion Prediction API

### Features

- Analyze text to identify emotions.
- Display the dominant emotion.
- Handle blank input errors.
- Perform static code analysis and code quality checks.
